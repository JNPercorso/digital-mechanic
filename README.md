# Цифровой механик

AI-агент для механика: объясняет результат акустической диагностики двигателя, отвечает по руководствам со ссылкой на страницу PDF и оформляет заявку на дефектовку.

Проект хакатона «ИИкузница», задача «Цифровой механик» (ООО «НейроДВС»). Инструкция по запуску будет дописана.

## База знаний (руководства по двигателям)

PDF заводских руководств и поисковый индекс с извлечённым из них текстом **не входят в репозиторий** и в историю коммитов: это требование организаторов по авторским правам. Они хранятся отдельно, в среде с ограниченным доступом, и подключаются через настройки.

1. Получите шесть PDF у организаторов хакатона (раздел 3 ТЗ) и положите их в папку из `MANUALS_DIR` (по умолчанию `manuals/`) под такими именами:

   | Файл | Документ |
   |---|---|
   | `yamz-236_re_2010.pdf` | ЯМЗ-236М2, руководство по эксплуатации 236-3902150-Б РЭ |
   | `yamz-236_rk_2014.pdf` | ЯМЗ-236М2, руководство по ремонту 236.01.01 РК |
   | `yamz-536_re_2016.pdf` | ЯМЗ-536, руководство по эксплуатации 536.3902150 РЭ |
   | `yamz-536_rk_2013.pdf` | ЯМЗ-536, руководство по ремонту 536.01.02 РК |
   | `zmz-5234_rk_2025.pdf` | ЗМЗ-5234.10, руководство по ремонту |
   | `zmz-40904-40905_rk_2025.pdf` | ЗМЗ-40904.10 и ЗМЗ-40905.10, руководство по эксплуатации, ТО и ремонту |

2. Соберите индекс (один раз, около 2 минут; страницы без текстового слоя распознаются Tesseract, если он установлен):

   ```bash
   python -m app.rag build
   ```

   Индекс появится в папке из `INDEX_DIR` (по умолчанию `index/`).

Папки `MANUALS_DIR` и `INDEX_DIR` задаются в `.env` (образец в `.env.example`): базу знаний можно держать на другом диске или в закрытом хранилище. Соответствие документов и двигателей описано в `app/manuals.py`; чтобы добавить двигатель, достаточно добавить строку туда и пересобрать индекс.
