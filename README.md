# Цифровой механик

AI-агент для механика: объясняет результат акустической диагностики двигателя, отвечает по руководствам со ссылкой на страницу PDF и оформляет заявку на дефектовку.

Проект хакатона «ИИкузница», задача «Цифровой механик» (ООО «НейроДВС»). Инструкция по запуску будет дописана.

## Материалы задачи (руководства и данные заглушек)

Материалы задачи **не входят в репозиторий** и в историю коммитов (требование организаторов, п. 9.1 Положения):

- PDF заводских руководств по двигателям и поисковый индекс с извлечённым из них текстом;
- данные заглушек: карточки машин с результатами проверок, справочник неисправностей (`mocks/data/*.json`).

Код заглушек ML и ТОиР, их контракты (OpenAPI) и тесты в репозитории есть.

### Загрузка при развёртывании

Ссылка на архив материалов задачи задаётся переменной окружения `MATERIALS_URL` (в `.env`, образец в `.env.example`), а не в коде. Команда скачивает архив, раскладывает PDF и данные заглушек и собирает базу знаний:

```bash
python -m app.fetch_materials
```

Поддерживаются прямая ссылка на `.zip`, публичная ссылка Яндекс.Диска (файл или папка) и ссылка Google Drive на файл. Сборка индекса занимает несколько минут; страницы без текстового слоя распознаются Tesseract, если он установлен.

### Вручную

1. Положите шесть PDF в папку из `MANUALS_DIR` (по умолчанию `manuals/`) под такими именами:

   | Файл | Документ |
   |---|---|
   | `yamz-236_re_2010.pdf` | ЯМЗ-236М2, руководство по эксплуатации 236-3902150-Б РЭ |
   | `yamz-236_rk_2014.pdf` | ЯМЗ-236М2, руководство по ремонту 236.01.01 РК |
   | `yamz-536_re_2016.pdf` | ЯМЗ-536, руководство по эксплуатации 536.3902150 РЭ |
   | `yamz-536_rk_2013.pdf` | ЯМЗ-536, руководство по ремонту 536.01.02 РК |
   | `zmz-5234_rk_2025.pdf` | ЗМЗ-5234.10, руководство по ремонту |
   | `zmz-40904-40905_rk_2025.pdf` | ЗМЗ-40904.10 и ЗМЗ-40905.10, руководство по эксплуатации, ТО и ремонту |

2. Положите данные заглушек (`vehicles.json`, `fault_types.json` из папки `mock/data` материалов) в `mocks/data/`.

3. Соберите базу знаний: индекс руководств и карту их разделов.

   ```bash
   python -m app.rag build
   python -m app.sections build
   ```

   Индекс появится в папке из `INDEX_DIR` (по умолчанию `index/`).

Папки `MANUALS_DIR` и `INDEX_DIR` задаются в `.env`: базу знаний можно держать на другом диске или в закрытом хранилище. Соответствие документов и двигателей описано в `app/manuals.py`; чтобы добавить двигатель, достаточно добавить строку туда и пересобрать индекс.

## Ключи

Ключи и токены (GigaChat) задаются только переменными окружения в `.env`; файл `.env` в `.gitignore`. Сертификат Минцифры для GigaChat кладётся в `certs/` (тоже вне репозитория).
